# 🚀 AI Advent — День 21: Индексация документов и сравнение стратегий Chunking (RAG)

## 🛠 Проделанная работа
- Реализован модуль индексации документов (**`document_indexer.py`**), обрабатывающий корпус документов проекта (>30 страниц текста в сумме из `.md`, `.py` файлов и базы знаний в папке `docs/`).
- Реализованы **2 стратегии chunking**:
  1. **Fixed Size Chunking:** Разбиение текста на блоки фиксированного размера с нахлестом (overlap).
  2. **Structural / Semantic Chunking:** Интеллектуальное структурированное разбиение (в Markdown — по заголовкам `#`, `##`; в Python — по функциям `def ` и классам `class `).
- Создан MCP-сервер индексации (**`mcp_server_indexer.py`**) с инструментами `build_document_index`, `search_document_index` и `compare_chunking_strategies`.
- Настроен нативный **Tool Calling**, позволяющий ИИ-агенту самостоятельно оркестрировать и использовать поисковый индекс при ответах на вопросы в чате.
