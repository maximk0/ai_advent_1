# 🔥 AI Advent — День 28. Локальная LLM + RAG

> **Ветка репозитория:** `day28`
> **Дата обновления:** 2026-10-12

Подключаем локальную языковую модель к существующему RAG-пайплайну. Поиск выполняется локально по ранее созданному индексу, а найденные фрагменты передаются локальной Qwen и выбранной облачной модели для сравнения ответов.

## Что реализовано

- Основной интерфейс сохранён: вкладка **«Чат»** с сайдбаром и вкладка **«Сравнение»**.
- В выборе модели в сайдбаре доступна локальная **Qwen3 4B Q4_K_M** через `llama.cpp`.
- Обычный чат сохраняет историю, настройки, управление памятью, профили и настройки RAG.
- В сравнении можно выбрать один из 10 контрольных вопросов с ожидаемым результатом и источниками или ввести собственный вопрос.
- Для локального и облачного ответов используется один и тот же контекст, найденный по вопросу в локальном индексе.
- В результатах рядом показаны ответы, модели и время генерации. Найденные источники и фрагменты можно раскрыть отдельно.
- Сценарий диалога с памятью задачи из Дня 25 сохранён в сворачиваемом блоке вкладки «Сравнение».
- При отсутствии фрагментов выше порога RAG сообщает, что не знает ответ, вместо запроса к модели без контекста.

## Окружение

- MacBook Air с Apple M4 и 16 ГБ памяти.
- `llama.cpp` и модель `Qwen/Qwen3-4B-GGUF:Q4_K_M`.
- Python 3.10 или новее.
- Для облачного сравнения нужен `OPENROUTER_API_KEY` в файле `.env`. Локальный чат и локальный ответ в сравнении используют llama.cpp.

## Запуск

### 1. Запустите локальную модель

Если `llama-server` уже работает, оставьте его запущенным. Иначе откройте отдельное окно Терминала и выполните:

```bash
llama-server -hf Qwen/Qwen3-4B-GGUF:Q4_K_M --jinja
```

Сервер модели должен быть доступен по адресу `http://127.0.0.1:8080`. Ответ `404 File Not Found` при открытии корневого адреса в браузере сам по себе не означает ошибку: приложение обращается к HTTP API по адресу `/v1/chat/completions`.

### 2. Запустите веб-приложение

В другом окне Терминала из папки проекта выполните:

```bash
cd /Users/uka/ai_advent_1
python3 day25.py
```

Откройте [http://127.0.0.1:8001](http://127.0.0.1:8001). Файл `day28.py` также запускает этот основной интерфейс.

### 3. Используйте чат или сравнение

- **Чат:** выберите в сайдбаре `Qwen3 4B Q4_K_M · локально (llama.cpp)`. При включённом RAG ответ строится по найденным документам и сопровождается источниками и цитатами.
- **Сравнение:** откройте вкладку «Сравнение», нажмите на контрольный вопрос либо введите свой. Выберите облачную модель и запустите сравнение. Поиск выполняется один раз, а одинаковые найденные фрагменты отправляются обеим моделям.
- Настройки поиска — query rewrite, Top-K и порог similarity — управляются в сайдбаре и влияют как на чат, так и на сравнение.

## Индекс и поиск

Приложение переиспользует `document_index.json`, созданный ранее. Индекс не перестраивается; поиск ограничен документами из `docs/`.

Текущий retrieval — локальный лексический поиск с нормализацией слов, синонимами, фильтром релевантности и Top-K. **Эмбеддинги и векторная база в этом индексе не используются.** Поэтому поиск в основном опирается на совпадения слов и настроенные правила, а не на векторное сравнение смысла.

Оценка контрольных вопросов помогает сверить ожидаемые факты и источники с ответами и найденными фрагментами. Автоматическая проверка совпадений является ориентиром; смысл ответа следует оценивать самостоятельно.

## Проверка через API

Локальную модель можно проверить отдельно от веб-интерфейса:

```bash
python3 day26_local_llm.py
```

Скрипт отправляет в llama.cpp три запроса разной сложности. Это проверяет HTTP API модели без RAG; в задании Дня 28 работу RAG нагляднее демонстрировать во вкладке «Сравнение».
