# Справка поддержки ПланФлоу

ПланФлоу — вымышленная B2B SaaS-платформа для управления проектами и командами. Правила и организации ниже созданы для учебной демонстрации.

## Внешний аудитор: доступ только к отчётам

На тарифе Business администратор может создать пользовательскую роль. Для роли аудитора разрешите раздел «Отчёты» и запретите раздел «Задачи». После этого пригласите аудитора в нужное рабочее пространство и назначьте ему эту роль. Внешний пользователь занимает одно место в лимите участников компании; перед приглашением проверьте доступные места.

## Лимит участников и приглашение пользователя

Тариф Team допускает до 20 участников в одном рабочем пространстве. При достижении лимита приглашение следующего пользователя недоступно. Администратор может освободить место, удалив участника, которому больше не нужен доступ, либо перейти на тариф с большим лимитом. Не удаляйте участников без подтверждения клиента.

## Вход из офиса при включённом списке IP-адресов

В тарифе Enterprise администратор может ограничить вход разрешёнными IP-диапазонами. Запросы с адресов вне списка блокируются до аутентификации, в том числе при корректной настройке SAML. Проверьте публичный IP нового офиса и попросите ИТ-администратора сверить его с allowlist в настройках безопасности. Если диапазон нужно добавить, изменение выполняет администратор организации; поддержка не обходит ограничение и не отключает его за клиента.

## Безопасность данных клиента

Не запрашивайте пароли, коды MFA, API-ключи, токены сессии или содержимое файлов клиента. Для диагностики достаточно названия рабочего пространства, времени ошибки, текста ошибки без секретов и описания выполненного действия.
