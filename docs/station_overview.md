# Паспорт вымышленной оранжереи «Сова-17»

Этот документ описывает учебный проект, факты которого придуманы специально для демонстрации поиска по документам. «Сова-17» не является реальной станцией или коммерческим объектом.

## Объект и команда

Оранжерея «Сова-17» находится на вымышленном плато Меловой Ключ. Её внутренний код площадки — SK-17, а диспетчерский позывной — «Сова». Комплекс состоит из двух куполов: «Иней» (основной) и «Роса» (рассадный).

За ежедневный журнал отвечает техник Лада Миронова. Резервный дежурный — Тимур Векшин. Смена передаётся в 08:10 по местному времени через запись в журнале `sv17-shift.log`; устное сообщение не заменяет запись.

## Посевы и вместимость

В куполе «Иней» ровно 28 гряд, пронумерованных I-01—I-28. В куполе «Роса» 12 лотков, обозначенных R-01—R-12. Основная культура — карликовая фасоль сорта «Лазурь-4». В рассадном куполе выращивают салат «Тихий лист».

Первый тестовый посев «Лазури-4» начался 14 марта 2025 года. Контрольная дата подсчёта всходов — 22 марта; нормой считается не менее 23 занятых гряд из 28. Эти числа относятся только к вымышленному проекту «Сова-17».

## Запреты

Не переносить лотки из «Росы» в «Иней» без отметки Лады Мироновой. Не называть SK-17 номером купола: это код площадки. Купола называются только «Иней» и «Роса».
