# CHANGELOG.md

## Было изменено

### Added: v1.0.0 — Вкладка «Файлы проекта»
Добавлена новая функциональность для взаимодействия с файлами проекта. Реализован модуль `project_file_tools.py`, который позволяет:
- Самостоятельно искать совпадения по текстовым файлам проекта (`.md`, `.py`, `.html`, `.txt` и др.)
- Анализировать найденные фрагменты с указанием пути, раздела и `chunk_id`
- Показывать unified diff для изменений
- Генерировать и сохранять обновленные Markdown/TXT документы
- Ограничивать операции только документацией в корне репозитория и папке `docs/`

Эта вкладка интегрируется в основной чат и обеспечивает автоматизированную подготовку документации по запросу. Также упоминается связь с MCP-инструментами для получения контекста из файлов `docs/support/faq.md` и других ресурсов.

Модуль `project_file_tools.py`:
- Определяет допустимые расширения файлов (`.md`, `.txt`)
- Исключает папки с `git`, виртуальным окружением и билд-директориями
- Закрывает доступ к секретам, истории чатов и сгенерированным индексам
- Поддерживает создание диффа и сохранения документа по кнопке

Документация по работе с файлами также доступна в `docs/project_guide.md` и вставлена в project index (`project_index.json`).

## Было оставлено без изменений
- Основной функционал репозитория (main.py, chat_ui.py, simple_agent.py, project_rag.py, etc.)
- Структура HTML-шаблона `chat_ui.py`
- Индикаторы API и HTTP endpoints
- Автоматическое ревью кода и поддержка
- Прочие разделы документации (IR/climate, RAG evaluation questions)

## Готовность
Добавленная вкладка «Файлы проекта» полностью интегрирована и готова к использованию. Она предоставляет удобный способ находить и анализировать конкретные фрагменты кода и документации, а также создавать актуализированные версии README и других документов.
