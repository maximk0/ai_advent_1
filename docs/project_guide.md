# Справочник по проекту AI Advent

Этот файл описывает устройство репозитория для команды `/help`. Он дополняет документы учебной оранжереи и README проекта.

## Основные части

- `main.py` — HTTP-сервис и веб-интерфейс. Он связывает существующий чат с локальной Qwen и облачными моделями, обслуживает API, ограничивает размер и частоту запросов, а также обрабатывает `/help`.
- `chat_ui.py` — HTML-шаблон основного чата и боковой панели.
- `simple_agent.py` — диалоговая логика, история, задача-память, генерация и интеграция найденных RAG-фрагментов.
- `document_indexer.py` — chunking, лексический поиск и фильтрация существующего индекса документов.
- `document_index.json` — индекс документов учебной оранжереи для обычного чата.
- `project_rag.py` — построение отдельного индекса README, этого справочника, описаний API и ключевых файлов проекта для `/help`. `project_index.json` создаётся автоматически.
- `mcp_client.py` — клиент MCP поверх JSON-RPC и stdio.
- `mcp_server_git.py` — Git MCP-сервер. Инструмент `git_status_check` возвращает текущую ветку и статус файлов; команда `/help` вызывает только его.
- `docs/` — документы оранжереи «Сова-17» и справочник по устройству приложения.

## Запуск

Сначала запустите локальную модель в одном окне:

```bash
llama-server -hf Qwen/Qwen3-4B-GGUF:Q4_K_M --jinja --ctx-size 8192 --parallel 1
```

Затем в другом окне запустите веб-приложение из корня репозитория:

```bash
python3 main.py
```

Чат откроется на `http://127.0.0.1:8030`. Для доступа с другого устройства в доверенной домашней Wi-Fi сети запустите `DAY30_HOST=0.0.0.0 python3 main.py`, затем откройте напечатанный адрес `http://<IP-компьютера>:8030` и введите одноразовый ключ из терминала.

## HTTP API

- `POST /api/chat` — сообщение из веб-чата. По умолчанию использует индекс оранжереи; сообщения `/help` переключают поиск на документацию и код проекта.
- `GET /api/state` — история чата и настройки интерфейса.
- `POST /api/config` — сохранить параметры боковой панели.
- `POST /api/clear` — очистить историю.
- `GET /api/day30/status` — состояние локальной модели, индекса и лимитов.
- `POST /api/day30/stability` — последовательная проверка нескольких локальных запросов.
- `POST /v1/chat/completions` — OpenAI-совместимый локальный чат.
- `GET /v1/models` — список доступной локальной модели.
- `GET /health` — проверка HTTP-сервиса.

## Вкладка «Помощь по проекту» и команда `/help`

Откройте вкладку «Помощь по проекту» и задайте вопрос обычным языком или выберите одну из готовых тем. Поиск выполняется локально по README, этому справочнику, API-описанию и выбранным исходным файлам. Ассистент получает найденные чанки с путём, разделом и `chunk_id`, а также актуальную ветку Git от MCP-инструмента `git_status_check`. Источники и цитаты показываются под ответом. В основном чате также доступна команда `/help` для этого же поиска.

Документы и код разбиваются на структурные чанки и индексируются лексическим поиском. Векторные эмбеддинги для этого индекса не используются. Проектный индекс сохраняется в `project_index.json` и обновляется при запуске сервиса.
